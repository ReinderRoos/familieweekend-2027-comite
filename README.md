# Familieweekend 2027 — besluitkader comité

Intern werkdocument voor het organiserend comité van het Van Doornik-familieweekend (4–6 juni 2027, De Bosbeek).

Open de pagina: **[besluitkader](https://reinderroos.github.io/familieweekend-2027-comite/)** (na GitHub Pages), of open `index.html` lokaal in je browser.

Deze repo bevat **alleen** dit besluitkader. Financiële detailbestanden en privécorrespondentie staan er bewust niet in.
